# 颜色清单
10 种彩色基色（彩色色轴）各自拥有严谨、固定的 13 阶 Hex 十六进制代码。

为了方便您在前端框架（如配置 Tailwind CSS、Sass 或 CSS 变量）中直接一键复制应用，现已为您将官方色板中**全部彩色的完整 13 阶 HEX 代码**以 Markdown 矩阵清单的形式为您完整标注并整理如下。

---

## 💡 前端提取无障碍（WCAG）规范指南

根据 W3C 与 DADS 标准，表格中的各个色阶在纯白背景（`#FFFFFF`）环境下，通常遵循以下无障碍提取规律：

* **`050` 至 `300` 阶梯（浅色区）**：对比度通常小于 `4.5:1` 或 `3:1`。在前端开发中，**严禁**作为普通字色，专门用于组件的背景（Background）、浅色标签、或禁用状态（Disabled）。
* **`400` 至 `500` 阶梯（临界区）**：需要搭配特定字号或加粗通过测试，通常不建议直接裸奔作为正文，常用于 Hover 的物理过渡状态。
* **`600` 至 `950` 阶梯（深色区）**：对比度完美 $\ge 4.5:1$。全站任何核心功能的文字（Text Line）、重要图标（Icon），必须从此区间中提取对应的基准 HEX 保证可读性。

## 三、 基于基色提取的标准语义映射表（生产级参考）

在开发数字服务时，您可以直接建立如下的别名（Alias / Semantic Tokens）来锚定上面的底层基色代码，彻底达到与 DADS 规范同等标准的设计约束：

```css
:root {
  /* 品牌基本交互 */
  --interactive-link-default: var(--color-blue-600);    /* #0064DD */
  --interactive-link-visited: var(--color-magenta-700); /* #960081 */

  /* 成功状态定义 */
  --semantic-success-text:    var(--color-green-700);   /* #006E06 - 满足文本 4.5:1 */
  --semantic-success-border:  var(--color-green-400);   /* #42B34B - 满足图形 3:1 */
  --semantic-success-bg:      var(--color-green-050);   /* #EDF7ED - 背景垫底 */

  /* 错误状态定义 */
  --semantic-error-text:      var(--color-red-500);     /* #D11919 - 满足文本 4.5:1 */
  --semantic-error-border:    var(--color-red-400);     /* #E73535 - 满足图形 3:1 */
  --semantic-error-bg:        var(--color-red-050);     /* #FCEBEB - 背景垫底 */

  /* 警告状态定义 */
  --semantic-warning-text:    var(--color-yellow-800);  /* #7A6700 - 调暗以满足文本 4.5:1 */
  --semantic-warning-border:  var(--color-yellow-400);  /* #FFDA00 - 满足图形 3:1 */
  --semantic-warning-bg:      var(--color-yellow-050);  /* #FFFCE6 - 背景垫底 */
}

```
