# QueryDoc 安装与运行环境说明

QueryDoc 是一款**完全离线可用**的桌面应用：在本地完成 PDF 的 OCR 解析、关键词信息提取与结果导出。OCR 引擎（PP-OCR）与 PDF 渲染库已全部内置在安装包中，**安装后即可直接使用，无需任何额外环境配置**（不需要安装 Node.js、Python、Docker 或数据库）。

---

## 一、支持平台与安装包

| 平台 | 安装包 | 状态 |
| --- | --- | --- |
| macOS（Apple Silicon） | `QueryDoc_<版本号>_aarch64.dmg` | 当前提供 |
| Windows x64 | 安装程序（后续提供，打包流程与 macOS 一致） | 计划中 |

应用为单机本地软件，不联网也能完成解析；仅「LLM 信息提取」环节可选地调用本地 Ollama 或 OpenAI 兼容 API（如 Kimi），在应用内「设置」中自行配置。

---

## 二、硬件要求

PP-OCR 的文本检测（det）、识别（rec）、方向分类与纠偏模型均在 **CPU 上以 ONNX Runtime 本地推理**，对显卡无要求；处理速度主要取决于 CPU 多核性能与内存大小。

### macOS

| 项目 | 最低要求 | 推荐配置 |
| --- | --- | --- |
| 机型 | Apple Silicon（M1 及以后） | M2 及以后 |
| 内存 | 8 GB | 16 GB 及以上 |
| 磁盘 | 2 GB 可用空间（应用 + 内置模型约 0.3 GB，余量给任务数据） | 10 GB 以上 |
| 系统 | macOS 12 (Monterey) 及以上 | 最新稳定版 |

### Windows

| 项目 | 最低要求 | 推荐配置 |
| --- | --- | --- |
| CPU | x86-64（近 3 年的 Intel/AMD 桌面或移动处理器） | 4 核 8 线程及以上 |
| 显卡 | 无要求（OCR 走 CPU 推理） | — |
| 内存 | 8 GB | 16–32 GB |
| 磁盘 | 2 GB 可用空间 | 10 GB 以上 |
| 系统 | Windows 10 64 位（1809 及以上） | Windows 11 |

> 说明：批量解析多页 PDF 时 OCR 为计算密集型任务，内存占用随页数与并发量上升。16 GB 内存可流畅处理常见合同/单据（单文件数十页）；内存较小（8 GB）时建议单次少量文件。

## 三、macOS 安装步骤

1. 双击打开 `QueryDoc_<版本号>_aarch64.dmg`。
2. 将 **QueryDoc** 拖入 **Applications（应用程序）** 文件夹。
3. 首次启动：本应用未经过 Apple 公证，系统可能提示「无法验证开发者」。任选一种方式放行：
   - 在「应用程序」中找到 QueryDoc，**按住 Control 点按（或右键）→ 打开 → 打开**；
   - 或打开一次后在 **系统设置 → 隐私与安全性** 中点击 **「仍要打开」**。
4. 之后即可正常双击启动。

## 四、Windows 安装步骤（后续提供）

1. 运行安装程序，按向导完成安装。
2. 首次启动若出现 SmartScreen 提示，选择 **「更多信息」→「仍要运行」**。
3. 安装完成即可使用，同样无需其他运行环境。

---

## 五、首次使用与可选配置

1. 打开应用即进入「项目」页，点「新增任务」创建任务（任务名称、所属项目、存放目录）。
2. 在任务内按时间线操作：上传 PDF → 解析文件 → 编辑关键词 → 提取信息 → 导出结果。
3. **「解析」完全离线可用**（内置 PP-OCR 与 PDF 渲染）。
4. **「提取」需要配置 LLM 服务**（可选）：
   - 本地 Ollama：默认地址 `http://localhost:11434`（需自行安装 Ollama 并拉取模型）；
   - OpenAI 兼容 API：如 Kimi 开放平台，`https://api.moonshot.cn/v1` + API Key。
   - 在应用右上角「设置」中填写并「连接测试」确认。不配置时仅提取功能不可用，其余功能不受影响。

## 六、数据存放位置

- **任务数据**：由你在创建任务时自选的目录（原始 PDF、解析结果、导出结果都在其中，目录结构清晰可直接浏览）。
- **应用数据库与设置**：系统应用数据目录（macOS 为 `~/Library/Application Support/com.querydoc.app/`，Windows 为 `%APPDATA%\com.querydoc.app\`），卸载应用后可手动删除以彻底清除。

## 七、卸载

- macOS：将「应用程序」中的 QueryDoc 移入废纸篓；如需清除数据，再删除上述应用数据目录及你自己创建的任务目录。
- Windows：通过「设置 → 应用」卸载；数据目录同样需手动删除。
